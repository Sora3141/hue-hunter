# Hue Hunter — 色相識別テスト

並んだタイルのうち **1枚だけ色相が違うマス**を探し当てる、色覚・色相弁別のテストです。
Firebase によるログインとランキング同期に対応しています。

## 遊び方

Season 2 / Time Attack。

- 持ち時間 12 秒から開始。1枚だけ色相の違うタイルを選ぶ。
- 正解すると**残り時間が回復**する（回復量は 3.0 秒から 1.4 秒へ逓減）。
- 残り時間の**上限も縮んでいく**ため、時間を貯め込んで安全に進むことはできない。
- スコアに応じてグリッドが **2×2 から 10×10 まで 9 段階**で細かくなる（3 / 7 / 12 / 18 / 26 / 36 / 48 / 62 点）。
- 色相差は **18° から 1.2° へ逓減**。**誤答**または**時間切れ**で終了。
- 終了時に、その回で**識別できた最小の色差**が記録される。これがテストの測定結果にあたる。
- 操作はタップ（クリック）だけ。縦画面のスマホで最後まで遊べる。
- 一時停止は HUD 右上のボタン、PC では P / Esc キーでも可。
- ログインせずにゲストで計測でき、記録は端末内に保存される。ランキングに載せるときだけ Google ログイン（Firebase）を使う。

## 開発

```sh
python3 -m http.server 8000
# http://localhost:8000 を開く
```

Google ログインは `localhost` を Firebase Authentication の承認済みドメインに追加しておくこと。

### Firestore のルールを公開する

`firestore.rules` を変えたら、Firebase に公開しないと本番には効かない（公開し忘れると `rankings_v2` の読み書きが `permission-denied` になる）。

```sh
npx firebase-tools login                              # 最初の 1 回
npx firebase-tools deploy --only firestore:rules      # firebase.json / .firebaserc の設定で huehunterworld に公開
```

Firebase コンソール > Firestore Database > ルール に `firestore.rules` を貼って「公開」してもよい。
Google ログインを使うので、Authentication > 設定 > 承認済みドメイン に `sora3141.github.io` と `localhost` を入れておく。


ビルドやテストの手順はない（静的ファイルをそのまま配信する）。Firestore の設定は下の「Firestore」を参照。

> `color-test` リポジトリは本ゲームのローカル版（"Ultimate"）です。

## UI 設計の方針

インターフェースは「計測器」として設計している。

1. **クロームは完全無彩色（R = G = B）。** 画面上で彩度を持つのは盤面だけ。有彩色の UI は同時対比で
   色相知覚をずらし、テストそのものを汚染する。背景色も色味を持たない中性グレーに揃えている。
2. **フィードバックは輝度と動きで表す。** 残り時間の警告にも赤を使わず、リングの明滅で伝える。
3. **開示では色を変えない。** 誤答・時間切れのあと、正解の位置は枠線と拡大だけで示し、
   すべてのタイルの色をそのまま残す。正解と基準色をその場で見比べられることがテストとしての価値なので、
   他のタイルを無彩色に落としたり暗くしたりしない。
4. **タイマーは盤面の枠。** 視線は盤面にあるため、離れた位置のバーではなく周辺視で捉えられる位置に置く。
5. **数値は等幅・タブular。** 桁がぶれないので、増減が形として読み取れる（IBM Plex Mono）。
6. **盤面以外の操作子はプレイ中に出さない。** 一時停止は HUD のボタン（または P / Esc）から。
   一時停止中は盤面を完全に伏せる。

### イラスト

すべて SVG の幾何図形で、script.js / index.html の中で描いている（画像ファイルなし）。

| 図 | 場所 | 内容 |
|---|---|---|
| 色相の虹彩 | タイトル | 4 重のタイル環で描いた色相環。1 片だけ色相をずらしてあり、タップすると見つけた印が付く。 |
| 計器ダイヤル | 結果 | 270° の無彩色メーター。100 点までの到達度を目盛りで、称号の境目を長い目盛りと段位番号で示す。 |
| 遊び方の図解 | タイトル | 3 手順を単色のピクトグラムで示す。 |
| 色見本 | 結果 | 最後の盤面の基準色と違う色を並べ、見分けられなかった色差を実物で示す。 |

称号には絵文字を使わない（絵文字は有彩色で、方針 1 に反する）。

### 測定環境（周辺色）

設定から周辺色を **ダーク / グレー / ライト** の3段階で選べる。いずれも中性グレー。
色の見えは周辺の明るさで変わり、色評価の標準は中性グレー（グレー設定）にあたる。

## 難易度の設計

色相差は一律ではなく、色相帯ごとに補正倍率を掛けている（マクアダム楕円 + 生理光学）。
人間の色相弁別能は橙〜黄で最も鋭く、緑帯で最も鈍いため、鈍い帯ほど色差を広げて体感難度を揃えている。

| 色相帯 | 倍率 |
|---|---|
| 緑 (80–165°) | 1.8 |
| シアン (166–210°) | 1.3 |
| 青〜紫 (211–280°) | 1.2 |
| 赤〜ピンク (320–360°, 0–20°) | 1.15 |
| 橙〜黄 (21–79°, 281–319°) | 1.0（基準） |

難易度カーブは [script.js](script.js) 冒頭の `TIME_START` / `GRID_STEPS` / `timeBonusFor` /
`timeCapFor` / `hueDiffFor` に集約してあるので、ここだけ触れば調整できる。

| score | grid | Δ 基準 | Δ 緑帯 (1.8倍) | 回復 | 上限 |
|---|---|---|---|---|---|
| 0 | 2×2 | 18.0° | 32.4° | +3.0s | 15.0s |
| 12 | 5×5 | 12.5° | 22.5° | +2.5s | 13.3s |
| 26 | 7×7 | 8.2° | 14.7° | +2.0s | 11.6s |
| 36 | 8×8 | 6.0° | 10.8° | +1.7s | 10.4s |
| 48 | 9×9 | 4.2° | 7.5° | +1.5s | 9.3s |
| 62 | 10×10 | 2.7° | 4.9° | +1.4s | 8.0s |
| 75 | 10×10 | 1.8° | 3.3° | +1.4s | 7.1s |
| 90 | 10×10 | 1.2° | 2.2° | +1.4s | 7.0s |

下限の 1.2° は `hsl(h, 80%, 50%)` で RGB 約 4 段階の差にあたり、8bit 表示で表現できる下限に近い。

## シェア

- **結果のシェア**（結果画面の共有アイコン）: 計器ダイヤル・称号・最小識別色差とその 2 色を描いた
  **スコアカード画像（1080×1350）**を canvas で生成し、端末の共有シート／X／LINE／リンクのコピー／画像の保存から送れる。
- **アプリのシェア**（タイトル画面の「シェア」）: 紹介文とリンクを共有する。
- 端末の共有シートは Web Share API。画像はシートを開いた時点で先に描いておく
  （共有ボタンを押してから描くと、Safari がユーザー操作と見なさず拒否するため）。
- リンクのプレビュー用に OGP / Twitter Card を設定済み（`icons/og.png`、1200×630）。
- シェア先 URL は `SHARE_URL`（script.js）に固定している。ドメインを変えたらここと index.html の `og:*` を直す。
