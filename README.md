# Hue Hunter — 色相当てゲーム（クラウド同期版）

並んだタイルの中から **1 つだけ色が微妙に違うマス**を探し出す、色覚・色相の識別ゲームです。
進むほどマス数が増え、色の差も小さくなっていきます。Firebase によるログイン＆ランキング同期に対応しています。

## 🔗 リンク

- リポジトリ: https://github.com/Sora3141/hue-hunter
- デモ: https://sora3141.github.io/hue-hunter/

## 概要

- 制限時間内に「色が違う 1 マス」を当て続けてスコアを伸ばす。
- レベルが上がると **グリッドが細かく・色差が小さく**なり難化。
- **ランキング**表示。ログインするとデバイス間で最高記録を同期。

## 使用技術

- HTML / CSS / Vanilla JavaScript
- **Firebase**（認証・スコアのクラウド同期）

> `color-test` リポジトリは本ゲームのローカル版（"Ultimate"）です。
